# 字幕对齐合并工具（Subtitle Align & Merge）

双版本 SRT 字幕对齐与合并的纯前端 Web 应用（React + TypeScript + Vite）。导入两份 SRT 后，系统按**时间重叠 + 文本相似度**进行顺序对齐，自动识别**一对一、一对多、多对一**以及单边片段；界面并排展示候选组与置信度，可逐组选择保留哪一版文本与时间轴，**未处理的冲突禁止导出**；合并结果可先做**滚动字幕消重**（识别连续滚动的同源字幕链并合并），再做**智能断行**（按显示宽度与行数限制自动分行），最终重新编号并校验时间单调性后下载为标准 SRT。无需任何外部服务，全部计算在本地完成。

## 一键启动（Docker）

```bash
docker compose up --build
```

启动后访问：**http://localhost:8080**（宿主机端口 `8080` → 容器内 nginx `80`）。

> 旧版 Compose 可使用 `docker-compose up --build`。若 8080 端口被占用，修改 `docker-compose.yml` 中 `ports` 左侧端口即可。停止：`docker compose down`。

## 使用流程

1. **导入双版本**：为版本 A / B 分别选择、拖入或粘贴 SRT 内容（可点击「加载示例数据」快速体验）。
2. **顺序对齐**：点击「开始顺序对齐」，系统生成对齐组，每组标注类型（一对一 / 一对多 / 多对一 / 仅 A / 仅 B）与综合置信度（文本相似度 60% + 时间重叠 40%）。
3. **解决冲突**：文本不一致或一对多 / 多对一的组会被标记为冲突（红色边框）。逐组选择保留的文本（A / B / 自定义）与时间轴（A / B / 并集 / 自定义），或用工具栏批量操作（全用 A/B、用较长文本、按建议解决全部）；单边片段可选择保留或丢弃。
4. **滚动字幕消重（可选）**：切换到「滚动字幕消重」页签，设置**最大相邻间隔**（默认 1.0 秒，下一条开始与上一条结束之差，支持时间重叠的负值）与**最小文本重叠**（默认 2 字）。系统在当前合并结果上识别连续滚动字幕链，展示原链各条、合并文本与节省字符数；可逐链「采纳 / 恢复」，也可「全部采纳 / 全部恢复」。修改参数后链即时重算，未采纳或已恢复的链不影响结果。
5. **智能断行（可选）**：切换到「智能断行」页签，设置每行最大宽度与最多行数后，逐条预览原文与断行结果。可单条「应用 / 恢复」，也可「全部应用 / 全部恢复」；无法满足限制的条目会标明原因并保持原文。断行只影响导出文本，不改变对齐、消重与冲突解决结果。
6. **校验导出**：右侧实时预览合并结果（含已采纳的消重链与已应用的断行）。存在未解决冲突或时间校验错误（开始时间倒退、区间重叠、时长非正、自定义时间非法）时无法导出；可勾选「自动修复时间重叠 / 非单调问题」。全部通过后点击「下载合并 SRT」，序号从 1 重新编排，导出始终使用已采纳消重、已应用断行的当前文本。

## 滚动字幕消重说明

- **相邻判定**：按合并结果出现顺序，下一条开始时间不早于上一条，且间隔 `下一条开始 − 上一条结束 ≤ 最大相邻间隔`（毫秒；负值表示两条显示时间重叠）。
- **重叠口径**：文本去除 HTML 标签（`<i>` 等）、ASS 覆盖标签（`{\an8}` 等）、标点与空白后得到字符序列（按 Unicode 码点切分，保留大小写）；相邻两项取**前一条最长后缀 ↔ 后一条最长前缀**的重叠长度（对后者建 KMP 前缀函数计算），重叠长度达到「最小文本重叠」才允许连接。
- **全局动态规划**：把每条可连接的相邻边视为带权区间（权重 = 重叠字符数），用带权区间调度 DP 选择**互不重叠的连续链**，按字典序依次：① 最大化累计消除的重复字符数；② 最小化合并组数（链数）；③ 同分时取更早链（链首下标更小，再依次比较链末与后续链）。
- **合并规则**：每条链只在首条全文之后依次追加后续各项**原文重叠位置之后的新增尾部**（标签、标点、空白按原文位置原样保留）；合并后时间取**链首条开始与末条结束**，序号在导出时统一重排。
- **采纳与恢复**：链的识别结果随参数与上游合并结果实时重算；每条链可单独采纳/恢复，也可全部采纳/全部恢复。参数变化后已失效的旧采纳自动忽略。预览与导出只使用已采纳的消重结果，智能断行在消重后的序列上进行。

## 智能断行说明

- **宽度计量**：按 Unicode 字素簇（grapheme cluster）计算显示宽度——全角字符计 2、半角计 1；HTML 标签（`<i>` 等）与 ASS 覆盖标签（`{\an8}` 等）原样保留在文本中但不计入宽度。
- **断点选择**：动态规划在空白或标点边界选择断点，依次最小化：① 超限宽度（超出每行最大宽度的总量）；② 行宽差（最窄行尽量宽、最宽行尽量窄）；③ 避头尾惩罚——行首为「，。！？；：、）】》」或行尾为「（【《」。
- **手工换行**：勾选「锁定已有手工换行」后，原文已有的换行作为不可跨越的边界（每段独立参与整体优化）；取消勾选则把已有换行当作普通空白，允许重新合并分行。
- **限制无法满足时**：若最优方案仍超宽（存在无法在空白/标点处断开的长片段）或所需行数超过上限，该条目标明原因且不应用，导出时保持原文；其余条目不受影响。
- **批量与逐条**：「全部应用」作用于所有可满足限制的条目；任意已应用条目可单独「恢复」为原文，「全部恢复」一键清空。修改参数后所有预览即时重算，导出始终使用当前文本。

## 对齐算法说明

- 文本归一化：去除 HTML/ASS 标签、标点与空白后小写化，对中英文均适用；相似度采用 bigram Dice 系数。
- 时间重叠：两时间段交集的 Dice 系数。
- 顺序对齐：带合并移动的动态规划（类序列比对），每个位置允许 1:1 匹配、N:1 合并、1:N 合并（单侧最多连续 4 条）与跳过（产生单边片段），全局最大化累计得分；大文件自动切换带状 DP 控制计算量。

## 项目结构

```
├── src/
│   ├── lib/
│   │   ├── srt.ts          # SRT 解析 / 序列化 / 时间码
│   │   ├── similarity.ts   # 文本与时间相似度
│   │   ├── align.ts        # 顺序对齐动态规划（1:1 / 1:N / N:1 / 单边）
│   │   ├── merge.ts        # 合并决策、时间单调性校验、自动修复
│   │   ├── scroll.ts       # 滚动字幕消重（后缀-前缀重叠 + 带权区间调度 DP）
│   │   ├── wrap.ts         # 智能断行（字素簇宽度 + 断点动态规划）
│   │   └── samples.ts      # 内置示例
│   ├── components/         # 导入、统计、工具栏、对齐组卡片、滚动消重、智能断行、导出面板
│   └── App.tsx             # 状态编排
├── Dockerfile              # 多阶段构建：node 构建 → nginx 托管
├── docker-compose.yml      # 一键启动，端口 8080 → 80
└── nginx.conf              # SPA 回退与静态资源缓存
```
